# 基于 ESP32-P4 的多模态 AI 无感健康守护与交互终端系统

这是面向主终端的真实状态查看网页，支持电脑布局和手机布局。网页从主终端读取生命体征、节点状态、融合结果和最近五天历史数据，也可以在浏览器中直接调用 DeepSeek 对当前数据进行健康分析。

## 使用

1. 将电脑和主终端接入同一局域网。
2. 用静态文件服务器打开当前目录，例如：

   ```powershell
   python -m http.server 8080
   ```

3. 在网页的“主控地址”输入主终端地址，例如 `http://192.168.1.100:8090`。
4. 点击“连接”，确认浏览器允许访问局域网 HTTP 服务。

网页不会内置 API Key。DeepSeek Key 只保存在浏览器本地存储，生产部署时建议通过后端代理或企业密钥管理服务保护密钥。
